# Civilian 66

Civilian 66 is a science-fiction exploration and mining game in development with Unreal Engine 5.8.2. Its modular design separates player control, reusable gameplay systems, economy, world simulation, and project-specific composition.

This public repository is a curated project reference. It documents the project's high-level architecture, code sets, and credited resources. It does not contain the complete game, its source implementation, the full Game Bible, or production assets.
